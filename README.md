# PayNest v1 — Final UI/UX

PayNest v1 เป็นเว็บแอปจัดการสัญญาผ่อนชำระแบบ Mobile-first โดยไม่ใช้ framework หรือ build step

## สิ่งที่คงไว้
- LocalStorage key เดิม: `paynest_v1_data`
- โครงสร้างข้อมูลเดิมและรองรับ JSON backup เดิม
- สร้างสัญญาได้ทันทีโดยไม่ต้องสร้างลูกค้าก่อน
- ถ้ากรอกชื่อลูกค้า ระบบสร้าง/ผูกลูกค้าให้อัตโนมัติ
- รับชำระหลายครั้งและคำนวณยอดคงเหลือ
- GitHub Pages จาก `main / (root)`

## สิ่งที่ปรับเพิ่มในรอบสุดท้าย
- UI/UX ใหม่ให้ใช้งานบนมือถือได้ง่ายขึ้น
- ปุ่ม + เปลี่ยนหน้าที่ตามบริบท: หน้า "ลูกค้า" = เพิ่มลูกค้า, หน้าอื่น = สร้างสัญญา
- แท็บสัญญา "กำลังผ่อน / ทั้งหมด / ชำระครบ" ใช้งานได้จริง
- ค้นหาสัญญาและลูกค้า
- หน้ารายละเอียดสัญญาและประวัติการรับชำระ
- แสดงจำนวนงวดและยอดประมาณต่องวด
- แก้การส่งออก JSON ให้ใช้ Blob type ที่ถูกต้อง
- ปรับการแสดงยอด/สถานะ/ปุ่มให้สม่ำเสมอทุกหน้า
- ไม่เปลี่ยน storage key เพื่อให้ข้อมูลเดิมยังใช้งานต่อได้

## Deploy
อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repository แล้วใช้ GitHub Pages:
`main` → `/(root)`

ไม่ต้องใช้ npm, framework หรือ build command
