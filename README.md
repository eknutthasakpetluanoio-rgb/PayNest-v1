# PayNest v1 — Final UI/UX
เวอร์ชันนี้ปรับ UI/UX และฟังก์ชันให้เป็นชุดเดียวกัน:
- ภาพรวมเน้นยอดค้างและรายการที่ต้องทำ
- สัญญาแยก กำลังผ่อน / ทั้งหมด / ชำระครบ
- ลูกค้าเชื่อมกับสัญญา
- รับชำระมีประวัติ
- รายละเอียดสัญญารวมยอดรวม / รับแล้ว / คงเหลือ / งวดถัดไป
- ตั้งค่ามี Export / Import / ล้างข้อมูล
- ใช้ LocalStorage key เดียว `paynest_v1`
- ไม่มีระบบเก่าปะปนและไม่ใช้ ES Module
