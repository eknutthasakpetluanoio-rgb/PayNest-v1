# PayNest v1 — Ready Build

ชุดนี้เป็นฐาน PayNest v1 ที่ล็อกแนวทาง UI/UX และโครงสร้างข้อมูลให้ทำงานร่วมกัน

## Flow หลัก
`+` → สร้างสัญญา → เลือกลูกค้าเดิมหรือ `+ ลูกค้าใหม่` → กรอกยอด/รูปแบบผ่อน/งวด → สร้างสัญญา

ไม่ต้องออกไปสร้างลูกค้าก่อน

## ฟังก์ชัน
- Dashboard เน้นยอดค้างและรายการที่ต้องจัดการ
- สัญญา: กำลังผ่อน / ทั้งหมด / ชำระครบ
- ลูกค้า: รายชื่อและจำนวนสัญญา
- สร้างลูกค้าใหม่จากหน้าสร้างสัญญา
- รายวัน / รายสัปดาห์ / รายเดือน
- จำนวนงวดและจำนวนเงินต่องวด
- รับเงินเริ่มต้น
- รับชำระเต็มงวด / ปิดยอด / กำหนดเอง
- ประวัติการรับชำระ
- คำนวณยอดคงเหลือและเปอร์เซ็นต์จาก payments ชุดเดียว
- วันงวดถัดไปขยับตามประเภทการผ่อน
- Export / Import JSON
- LocalStorage key เดียว: `paynest_v1`
- GitHub Pages compatible
